# Geral

> [!TIP]
> A ordem dos passos importa: nao pule a preparacao do ambiente.


Implementação do algoritmo de ordenação por flutuação, escrita em Python.

# Versão do interpretador

Usei a versão 3.8.5 na época.

# Execução

```
python index.py
```

O programa pede os números um de cada vez e ordena assim que você encerra a entrada com a tecla indicada no prompt.
